README

1 - What is SmartBudget Manager?
SmartBudget Manager is an Excel workbook that helps users manage their money. It shows income, expenses, and monthly balance.
2 - Requirements :
- Microsoft Excel
- Basic Excel skills
- A computer
3 - How to Start :
1. Open the Excel file. 
2. Go to the Transactions sheet.
3. Enter your income and expenses.
4. Choose the correct type and category.
5. Check the Dashboard to see your budget.
6. Save the file if you want to keep the result.
